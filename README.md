Netflix Data Cleaning & Visualization Project

Overview

This project analyzes Netflix's content dataset using Python. The dataset was cleaned, processed, and visualized to uncover insights about content types, countries, release trends, and audience ratings.

Technologies Used

* Python
* Pandas
* Matplotlib

Data Cleaning

* Handled missing values in director, cast, and country columns
* Checked for duplicate records
* Prepared the dataset for analysis

Visualizations

1. Movies vs TV Shows Distribution
2. Top 10 Countries Producing Netflix Content
3. Netflix Content Released by Year
4. Most Common Content Ratings

Key Insights

* Netflix contains significantly more movies than TV shows.
* The United States contributes the largest share of content.
* India is the second-largest contributor.
* Content production increased rapidly after 2015.
* The dataset contains a diverse range of audience ratings.
